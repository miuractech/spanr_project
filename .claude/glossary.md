# Glossary

| Term | Definition |
|---|---|
| **Company** | A mechanic business registered on SPANR. The unit of multi-tenancy. |
| **Owner** | A company admin/manager. Logs into the React dashboard. Has full access to their company's data. |
| **Staff / Mechanic** | An employee of a company. Logs into the Flutter mechanic app. Receives and executes job assignments. |
| **Customer / User** | An end user who books vehicle service through the Flutter user app. |
| **Order** | A service booking created by a customer. Goes through a lifecycle from `created` to `completed`. |
| **Plan** | A specific service package offered by a company (e.g., "Full Car Service - Petrol - Doorstep"). Belongs to a Service. |
| **Service** | A service category offered by a company (e.g., "General Service", "AC Repair"). Contains multiple Plans. |
| **Assignment** | The link between an Order and a Staff member. Only one can be `active` per order at a time. |
| **Job** | The mechanic's view of an order assignment. What appears in the mechanic app. |
| **Inspection** | The before/after photo documentation of a vehicle's condition. 4 angles (front, back, left, right). |
| **Service History** | A permanent, denormalized record of a completed job. Created by `complete_job()` RPC. Linked to vehicle. |
| **Paise** | 1/100th of an Indian Rupee. All Razorpay amounts are in paise. |
| **RLS** | Row Level Security — PostgreSQL mechanism enforcing data access at the database level. |
| **SECURITY DEFINER** | PostgreSQL function that runs with the privileges of its owner, not the caller. Used for RLS helpers. |
| **user_company_id()** | Critical SECURITY DEFINER function. Returns the company UUID for the currently authenticated staff member. Backbone of multi-tenancy. |
| **Hive** | A fast, lightweight local key-value database for Flutter. Used in the mechanic app for offline queue. |
| **Realtime** | Supabase feature providing WebSocket-based change notifications from PostgreSQL. Used by mechanic app to receive job assignments live. |
| **Edge Function** | Serverless function running on Deno, deployed to Supabase's infrastructure. Used for Razorpay integration and owner signup. |
| **must_change_password** | Flag in `staff_profiles`. Forces mechanics to set a new password on first login after provisioning. |
| **Temp password** | A one-time password generated by `provision-staff-auth` Edge Function. Shown once to the owner to give to the mechanic. |
| **KYC** | Know Your Customer — verification documents (GST certificate, PAN card, utility bill) uploaded by companies for identity verification. |
| **Doorstep** | A service location type where the mechanic comes to the customer's location. Opposite of in-shop. |
| **Bounding box** | The rectangular geographic region used for the first-pass mechanic search (SQL query). Followed by Haversine distance filter. |
| **Haversine** | Formula for calculating the great-circle distance between two points on a sphere given their lat/long coordinates. Used for 7km geo-filter. |
| **GoRouter** | Flutter navigation package. Used by both Flutter apps for declarative routing with guards. |
| **Provider** | Flutter state management pattern using `ChangeNotifier` + `ChangeNotifierProvider`. Used by both Flutter apps. |
| **VITE_*** | Environment variable prefix for variables exposed to the React/Vite frontend build. |
| **anon key** | Supabase publishable API key. Safe to embed in client code; RLS enforces authorization. |
| **service role key** | Supabase admin key that bypasses RLS. Must never leave the server (Edge Functions only). |
